# Facial Clinic CRM

מערכת ניהול לקוחות לקליניקת טיפולי פנים — ניהול לקוחות, יומן תורים, תשלומים, תמונות, ובהמשך אוטומציות תזכורות (אימייל/וואטסאפ).

## מבנה הריפו

```
facial-clinic-crm/
├── backend/      # FastAPI + Supabase
└── frontend/     # React + Vite + Tailwind
```

ראה README נפרד בכל תיקייה להוראות הרצה מפורטות.

## מצב נוכחי: שלב 1 — שרת Backend בסיסי + שלד Frontend

**מה קיים:**
- שרת FastAPI מלא עם 4 ישויות: לקוחות, תורים, תשלומים, תמונות
- חיבור ל-Supabase (DB + Storage)
- CRUD מלא לכל ישות + תיעוד אוטומטי ב-`/docs`
- שלד React עם ניווט, RTL, Tailwind, וחיבור בסיסי ל-API (עמוד לקוחות באמת מציג נתונים מהשרת)

**מה עדיין לא קיים (יגיע בשלבים הבאים):**
- Authentication
- עיצוב מתקדם ומלוטש (כרגע פונקציונלי בלבד)
- יומן תורים אינטראקטיבי
- העלאת תמונות ב-UI
- אוטומציות תזכורות
- Deploy לפרודקשן בענן

## השלב הבא

הקמת מסד הנתונים ב-Supabase (יצירת פרויקט, הרצת `supabase_schema.sql`, יצירת Storage bucket, והעברת המפתחות ל-`.env`).
